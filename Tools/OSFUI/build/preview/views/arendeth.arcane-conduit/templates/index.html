Spell Templates

Mod builds ship with the plugin. Personal builds live on this machine. Suggested builds are generated from the live banks (school, triggers, capacity, stability). Tagged files can auto-apply on a zone or suit change (school-on-draw is off by default). Distinct from F8 suggestions, which generate a layout. A fuse pair snapshots Grid A (element) plus Grid B (delivery); Apply aims both banks — hold the fuse modifier to mutate. Export copies a personal JSON to the Export folder. Drop received files in Import, then Import dropped. Shared files cannot grant essence, durability, or energy.
