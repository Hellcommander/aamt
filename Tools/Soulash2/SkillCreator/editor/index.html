Skill tree by unlock level

A level can grant both a milestone and +1 statistic. Stats are listed on the same row as the unlock, not instead of it.

Skill / mod.json

Official docs §5.1: starting_gear (first always grants, first+second is a create choice). Docs exp_sources omit walk, carve, and production — those are valid in live JSON. thumbnail is a 4:3 PNG for Steam. disable_portraits is global and overrides other mods — leave it off. File name is still ability_amplifiers.json (docs wrongly say amplifiers.json).

Stat points

Milestones stay on their unlock levels. The engine allows +1 statistic on the same level. Default keeps early vanilla stats (2, 4, 5, 7, 8, 10) then every level 11–49. Vanilla Pyromancy interleaves some empty post-10 levels, which is why a milestone can show with no +1. Filling 11–49 does not move anything.

Thematic 32×32 sheets: python s2_skill_cli.py generate-icons --id … --overwrite (starts the SD server; use --no-sd for procedural). write does not generate art.
