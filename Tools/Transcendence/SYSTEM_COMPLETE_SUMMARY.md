## 🚀 Usage

### Generate All Assets
```powershell
.\WeaponMutationGenerator.ps1 -RegistryPath weapon_mutation_example.json -OutputDir "TestOutput/WeaponMutations"
```

This generates:
1. XML definitions (`XML/weapon_mutations.xml`)
2. Behavior code (`Code/weapon_mutation_behaviors.xml`)
3. Balance report (`Balance/balance_report.txt`)

### Individual Components
```powershell
# XML only
python transcendence_weapon_mutation_exporter.py --registry weapon_mutation_example.json --output-dir "output/XML" --combined

# Behavior code only
python weapon_mutation_behavior_generator.py --registry weapon_mutation_example.json --output "output/behaviors.xml"

# Balance analysis only
python weapon_mutation_balancer.py weapon_mutation_example.json output/balance_report.txt
```
