## How to Use Placeholders

### Option 1: Use Best Variation Directly
1. Open `space_whale_fx_registry_placeholders.json`
2. Find the effect group (e.g., `space_whale_orbit_field`)
3. Use the rank 1 variation (best score)
4. Copy to your working registry

### Option 2: Compare and Choose
1. Review all 5 variations for an effect
2. Compare quality scores and notes
3. Select the one that best fits your needs
4. Use as starting point for manual editing

### Option 3: Manual Editing
1. Start with rank 1 variation
2. Review quality notes for improvement areas
3. Adjust parameters based on notes
4. Re-assess if needed

### Option 4: Generate Assets from Placeholders
```powershell
# Extract best variation from each effect group

.\NovaDriftFXGenerator.ps1 -RegistryPath "extracted_best_placeholders.json" -OutputDir "Output"
```

## Quality Notes Reference

### Visual Quality Issues
- "Color harmony could be improved" → Adjust color palette
- "Intensity may be too weak/strong" → Tune intensity (2.0-4.0 optimal)
- "Distortion may be too strong" → Reduce distortion strength

### Feature Completeness Issues
- "Missing core glow" → Enable core glow
- "Missing bloom" → Add bloom layer
- "No particles" → Add particle system
- "No distortion" → Add distortion field

### Technical Quality Issues
- "Sprite size may not be optimal" → Adjust size for effect type
- "High frame count may impact performance" → Reduce frames
- "High particle count may impact performance" → Reduce particles

### Aesthetic Appeal Issues
- "Style not explicitly Nova Drift" → Ensure style="novaDrift"
- "High-energy glow present" → Good! Maintain intensity
- "Smooth easing curves configured" → Good! Keep timing curves
