# Weapon Mutation Synergy Examples

## Active Synergies

### 1. Shred Mode + Condensed Rounds
**Effect**: "Fragments gain +20% damage and +1 additional fragment"
- Split count: 3 → 4 fragments
- Fragment damage: 80% → 96% (with synergy)
- **Gameplay**: Close-range shredder build

### 2. Pulsewave + Homing Seeker
**Effect**: "Pulses gain homing and track nearest enemy"
- Pulses: Random → Homing
- Damage: 60% → 69% (with synergy)
- **Gameplay**: Precision area damage

### 3. Lightweight Barrel + Overclock
**Effect**: "Speed bonus increases to +25% when combined"
- Speed: +15% → +25%
- **Gameplay**: Ultra-fast spam build

### 4. Entropy Bloom + Shred Mode
**Effect**: "Each fragment spawns its own shard on kill"
- Shards per kill: 1 → Multiple (one per fragment)
- **Gameplay**: Explosive chain reactions

### 5. Burning Rounds + Shred Mode
**Effect**: "All fragments apply burn"
- Burn chance: 25% → 40% per fragment
- **Gameplay**: DoT-focused build

### 6. Ricochet Rounds + Shred Mode
**Effect**: "Each ricochet splits into fragments"
- Ricochets: 3 bounces → 3 bounces + 2 fragments each
- **Gameplay**: Exponential projectile multiplication

### 7. Vortex Orb + Burning Rounds
**Effect**: "Orb gains burn aura, submunitions apply burn"
- Burn application: Standard → 80% chance on orb + submunitions
- **Gameplay**: Persistent burn field

## Synergy System Benefits

### More Interesting Combinations
- Mutations now create unique interactions
- Players discover new playstyles
- Build variety significantly increased

### Emergent Gameplay
- Synergies change weapon behavior
- Not just number tweaks
- Create distinct playstyles

### Balance Maintained

- Synergies require specific combinations
- Opportunity cost for synergy builds
