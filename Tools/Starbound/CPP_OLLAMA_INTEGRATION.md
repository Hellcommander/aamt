# C++ Backend Ollama Integration Guide

## Overview
The C++ backend can now use Ollama AI assistance through Lua bindings and PowerShell bridges. This enables high-quality asset generation with AI-enhanced descriptions.

## Architecture

### 1. PowerShell Bridge (`OllamaCppBridge.ps1`)
- Executable from C++ via `system()` or Lua `os.execute()`
- Actions: `enhance_description`, `extract_parameters`, `check_connection`
- Returns enhanced descriptions or JSON parameters

### 2. Lua Helper (`OllamaLuaHelper.lua`)
- Loaded by C++ generators via `require("OllamaLuaHelper")`
- Functions:
  - `OllamaHelper.isAvailable()` - Check if Ollama is running
  - `OllamaHelper.enhanceDescription(description)` - Enhance description
  - `OllamaHelper.extractParameters(description)` - Extract visual parameters
  - `OllamaHelper.enhanceProceduralParams(params, description)` - Full enhancement

### 3. Integration Flow

```
C++ Generator → Lua Script → OllamaLuaHelper → OllamaCppBridge.ps1 → Ollama API
                                                      ↓
                                              Enhanced Description/Parameters
                                                      ↓
                                              C++ Procedural Generation
```

## Usage in C++ Generators

### From Lua Scripts (Generated by Bridge)

The bridge automatically generates Lua scripts that:
1. Load `OllamaLuaHelper.lua`
2. Enhance descriptions using Ollama
3. Extract parameters for procedural generation
4. Pass enhanced data to C++ generators

### Direct C++ Integration (Future)

To add direct C++ Ollama support:

1. **Add HTTP client library** (e.g., cpp-httplib, libcurl)
2. **Create OllamaClient class**:
   ```cpp
   class OllamaClient {
       std::string enhanceDescription(const std::string& description);
       nlohmann::json extractParameters(const std::string& description);
       bool isAvailable();
   };
   ```
3. **Integrate into generators**:
   ```cpp
   ImageBundle ImageGenerator::generateImage(const ImageParams& params) {
       OllamaClient ollama;
       if (ollama.isAvailable() && !params.description.empty()) {
           std::string enhanced = ollama.enhanceDescription(params.description);
           params.description = enhanced;
       }
       // Continue with enhanced description...
   }
   ```

## Current Implementation

### PowerShell Bridge Commands

```powershell
# Enhance description
powershell.exe -ExecutionPolicy Bypass -File "OllamaCppBridge.ps1" `
    -Action enhance_description `
    -Description "A magical sword" `
    -OutputFile "enhanced.txt"

# Extract parameters
powershell.exe -ExecutionPolicy Bypass -File "OllamaCppBridge.ps1" `
    -Action extract_parameters `
    -Description "A magical sword" `
    -OutputFile "params.json"

# Check connection
powershell.exe -ExecutionPolicy Bypass -File "OllamaCppBridge.ps1" `
    -Action check_connection
```

### Lua Integration

```lua
require("OllamaLuaHelper")

-- Set bridge path
OllamaHelper.BRIDGE_SCRIPT = "C:\\path\\to\\OllamaCppBridge.ps1"

-- Enhance description
local enhanced = OllamaHelper.enhanceDescription("A magical sword")
print("Enhanced: " .. enhanced)

-- Enhance parameters
local params = { width = 64, height = 64 }
params = OllamaHelper.enhanceProceduralParams(params, "A magical sword")
```

config.model = "llama3.2";
config.enabled = true;
ollama.setConfig(config);

// Check availability
if (ollama.isAvailable()) {
    // Enhance description

### Integration into ImageGenerator

```cpp
ImageBundle ImageGenerator::generateImage(const ImageParams& params) {
    GeneratorAgent::OllamaClient ollama;
    
    if (ollama.isAvailable() && !params.description.empty()) {
        auto enhancement = ollama.enhance(params.description);
        if (enhancement && enhancement->description.wasEnhanced) {
            // Use enhanced description and parameters
            ImageParams enhancedParams = params;
            enhancedParams.description = enhancement->description.enhanced;
            // Apply extracted parameters...
            return processImageGeneration(enhancedParams);
        }
    }
    
    // Fallback to standard generation
    return processImageGeneration(params);
}
```

### Building

**Windows:**
- Uses WinHTTP (included with Windows SDK)
- No additional dependencies needed

**Linux/Mac:**
- Requires libcurl: `sudo apt-get install libcurl4-openssl-dev` (Linux)
- Link with: `-lcurl`
