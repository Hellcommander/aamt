# Spritesheet Packer Integration Summary

## Overview

The `StarboundAssetGenerator.ps1` has been enhanced to automatically use professional spritesheet packing tools (Aseprite CLI, Free Texture Packer) when available, with automatic fallback to manual packing.

## What Changed

### Modified Function: `Generate-AnimationSprite`

The animation spritesheet generation now:

1. **Checks for Packer Tool**: Automatically detects if `StarboundSpritesheetPacker.ps1` is available
2. **Generates Individual Frames**: Creates all animation frames at the correct resolution
3. **Saves Frames Temporarily**: If packer tool is available, saves frames to temp directory
4. **Always Draws to Spritesheet**: Frames are always drawn to spritesheet (for fallback)
5. **Attempts Tool-Based Packing**: If packer tool is available, uses it for optimized packing
6. **Falls Back Gracefully**: If packer fails or is unavailable, uses manually drawn spritesheet

## Benefits

- **Better Packing**: MaxRects algorithm (Aseprite) or bin-packing (Free Texture Packer) instead of simple horizontal strips
- **Power-of-Two Support**: Automatic POT sizing for GPU optimization
- **Consistent Padding**: Automatic padding and trimming to prevent texture bleeding
- **Zero Breaking Changes**: Fully backward compatible - works with or without packer tools
- **Automatic Fallback**: If packer tool fails, uses manual packing seamlessly

## How It Works

### Flow Diagram

```
Generate Animation Frames
    ↓
Create Individual Frames (at generation resolution)
    ↓
Scale Frames to Final Size
    ↓
Draw Frames to Spritesheet (always, for fallback)
    ↓
[If Packer Tool Available]
    ↓
Save Frames to Temp Directory
    ↓
Call StarboundSpritesheetPacker.ps1
    ↓
[If Packer Succeeds]
    ↓
Use Packer Output (optimized spritesheet + .frames file)
    ↓
[If Packer Fails]
    ↓
Use Manually Drawn Spritesheet (already created)
    ↓
Create .frames File (if packer didn't create it)
```

## Installation

### Option 1: Aseprite (Recommended)

1. Download Aseprite from https://www.aseprite.org/
2. Install normally (CLI is included)
3. Verify installation: `aseprite --version`

### Option 2: Free Texture Packer

1. Install Node.js: https://nodejs.org/
2. Install CLI: `npm install -g free-tex-packer-cli`
3. Verify installation: `free-tex-packer-cli --version`

### Option 3: No Installation

The system will automatically fall back to manual packing if no tools are available.

## Usage

No changes needed! The integration is automatic. When you generate animation spritesheets:

```powershell
# This automatically uses packer tool if available
Generate-AnimationSprite `
    -AssetName "spell_cast" `
    -Description "A magical spell casting animation" `
    -Parameters @{
        FrameCount = 8
        FrameWidth = 64
        FrameHeight = 64
    } `
    -OutputDir "assets" `
    -SpriteType "ItemSprite"
```

The function will:
- Try to use Aseprite CLI if available
- Fall back to Free Texture Packer if Aseprite unavailable
- Fall back to manual packing if no tools available

## Output

### With Packer Tool

- **Spritesheet**: Optimized with MaxRects/bin-packing algorithm
- **Power-of-Two**: Automatically sized to nearest POT (256, 512, 1024, etc.)
- **Padding**: Automatic padding between frames (2px default)
- **.frames File**: Generated by packer tool with correct metadata

### Without Packer Tool (Fallback)

- **Spritesheet**: Horizontal strip layout (same as before)
- **Dimensions**: Exact size (frame width × frame count)
- **Padding**: None (frames abut each other)
- **.frames File**: Generated manually with correct metadata

## Troubleshooting

### Packer Tool Not Detected

**Symptom**: "Spritesheet packer not found, using manual packing..."

**Solution**: 
- Install Aseprite or Free Texture Packer
- Ensure the tool is in your PATH
- Verify with `aseprite --version` or `free-tex-packer-cli --version`

### Packer Tool Fails

**Symptom**: "[WARN] Packer tool failed, falling back to manual packing..."

**Solution**:
- Check tool installation
- Verify frame files are valid PNGs
- Check disk space in temp directory
- System automatically falls back to manual packing

### .frames File Missing

**Symptom**: Animation doesn't work in Starbound

**Solution**:
- Check that `.frames` file exists next to spritesheet
- Verify JSON format is correct
- Check frame dimensions match spritesheet layout
