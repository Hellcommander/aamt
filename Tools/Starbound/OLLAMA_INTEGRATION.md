# Ollama Integration for Asset Generation
**AI-Assisted Modding Tools (AAMT)**

## Overview
All asset generation scripts now use Ollama AI assistance to improve quality. Ollama enhances descriptions and guides procedural generation for better results. This is part of the AI-Assisted Modding Tools (AAMT) suite.

## How It Works

### 1. Description Enhancement
- When a description is provided, Ollama enhances it with:
  - Specific color palette suggestions
  - Visual style details
  - Material/texture characteristics
  - Thematic elements

### 2. Parameter Extraction
- Ollama extracts visual parameters from descriptions:
  - Color palettes (RGB values)
  - Style hints (magical, metallic, crystalline, etc.)
  - Visual effects (gradients, patterns, sparkles)

### 3. Enhanced Generation
- Enhanced descriptions and parameters are passed to:
  - C++ backend generators (for procedural generation)
  - PowerShell generators (for description-based generation)

## Usage

### From PowerShell
```powershell
# All scripts automatically use Ollama when Description is provided
& "StarboundOllamaAssetGenerator.ps1" -AssetType "Sprite" -AssetName "my_asset" -Prompt "A magical sword"
```

### From C++ Backend
The Lua scripts generated by the bridge automatically:
1. Load `OllamaLuaHelper.lua`
2. Enhance parameters using the description
3. Pass enhanced parameters to C++ generators

## Requirements

1. **Ollama must be running**: `ollama serve`
2. **Recommended models**:
   - `llama3.2` - For description enhancement
   - `wizardlm-uncensored` - For creative descriptions
   - `codellama:7b-instruct` - For parameter extraction

## Benefits

- **Higher Quality**: Ollama-enhanced descriptions lead to better procedural generation
- **Consistency**: Thematic consistency across related assets
- **Flexibility**: Falls back gracefully if Ollama is unavailable
- **Integration**: Works with both PowerShell and C++ backend generators

## Fallback Behavior

If Ollama is unavailable:
- Scripts continue with original descriptions
- C++ backend uses standard procedural generation
- No errors are thrown, just warnings

## Notes

- Ollama enhances descriptions but doesn't generate images directly
- Image generation is handled by C++ backend or PowerShell generators
- Enhanced descriptions guide procedural generation for better results
- All generators respect the `Description` parameter when provided
